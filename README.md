## 🚀 Featured Engineering Work

### Multi-Vendor Appliance Telemetry Platform

An event-driven platform that integrates appliances from different vendors through
a consistent API and processes telemetry asynchronously.

**Highlights:**

- Vendor-specific Kafka topics and partitioning strategy
- PostgreSQL-backed metric history and reporting
- Quarantine flow for unknown appliances
- Retry, failure isolation and extensible vendor adapters
- Spring Boot services with a React dashboard

### OAuth2 Authorization Platform

Embedded an authorization server into an enterprise management platform.

**Highlights:**

- OAuth 2.0 and JWT-based authentication
- Spring Authorization Server
- Secure client registration and token validation
- Integration with enterprise device-management workflows

### Intelligent RCA Automation

Agent-assisted tooling for log analysis, root-cause identification and automated
remediation recommendations.
